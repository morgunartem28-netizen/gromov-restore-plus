Если обновление в программе не работает

1. Откройте лог: %LOCALAPPDATA%\GROMOV\RestorePlus\update_debug.log
2. Скачайте Setup по любой ссылке выше и установите поверх.
3. Версии ≤1.2.1 умеют проверять обновления только через raw.githubusercontent.com — если он заблокирован, нужен один раз Setup (браузер или удалённо scripts/silent_update.ps1), дальше на 1.2.7+ обновления идут автоматом через зеркала.
